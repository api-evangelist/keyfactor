# Keyfactor

> Keyfactor is a machine-identity and PKI (public key infrastructure) company that provides a control plane for digital trust — certificate lifecycle automation, quantum-ready PKI, code signing, and cryptographic discovery across enterprise, cloud, and IoT environments. Core products are Keyfactor Command (certificate lifecycle automation), EJBCA Enterprise (PKI/CA), SignServer/Signum (code signing), and Cloud PKI-as-a-Service. Backed by Insight Partners.

This is an API Evangelist catalog profile (generated from apis.yml and repo artifacts). Keyfactor Command exposes a REST Web API served per-customer from each self-hosted or cloud instance; EJBCA exposes a REST API as well. There is no single public hosted OpenAPI to link.
